📘 CanTrack v2.0 – Virtual Signals User Guide

Virtual signals let you create new signals on-the-fly using mathematical expressions based on existing CAN signals. This is useful for computing derived values like power, efficiency, ratios, clamped values, or unit conversions — all within the analyzer, without modifying your original data.

✅ 1. Where to Enter Virtual Signals

In the “Virtual Signal” section of the CanTrack sidebar:

  • Input field: ex: Power = Voltage * Current
  • Button: Click “Add Virtual Signal” to create it.

Once added, the new signal appears in the signal list and can be plotted, filtered, or used in other expressions.

✅ 2. Basic Syntax

Use this format:

NewSignalName = expression

Rules:

  • Exactly one = sign
  • Signal names must match those in your JSON data (case-sensitive)
  • No spaces in signal names (use underscores: Battery_Voltage)
  • Expression is evaluated at every time point using current values

✅ Valid Examples:

Power = Voltage * Current
Efficiency = (OutputPower / InputPower) * 100
ClampedTemp = Math.max(Math.min(Temperature, 120), -40)
SquaredRPM = Math.pow(RPM, 2)
Speed_kmh = Speed_mps * 3.6
Angle_rad = Angle_deg * Math.PI / 180

⚠️ 4. Common Mistakes

❌ Invalid: Missing arguments or syntax errors

tabit = Math.max(L_IORpt_Vbulk)     // ❌ Needs ≥2 args
tabit = Math.pow(P_VacRpt_Counter)   // ❌ Needs exponent
Power = Voltage *                    // ❌ Incomplete
New Signal = A + B                   // ❌ No spaces in name

⚠️ Technically runs but useless

tabit = Math.max(Signal)  // → just returns Signal

✅ Corrected versions:

tabit = Math.max(L_IORpt_Vbulk, 0)
tabit = Math.pow(P_VacRpt_Counter, 2)
Power = Voltage * Current
NewSignal = A + B

💡 5. Pro Tips

  • Chain virtual signals:
    Power = Voltage * Current
    Energy = Power * 0.01
  • Clamp noisy data:
    SafeVolt = Math.max(Math.min(RawVolt, 14.5), 11.0)
  • Unit conversion:
    SOC_pct = SOC_raw * 100

❓ Limitations

Virtual signals are computed point-wise (per timestamp). They cannot:

  • Access past/future values (no moving average)
  • Use conditional logic (if, ternary)
  • Perform time-based aggregations (min over 1s window)

👉 These features may be added in future versions.
